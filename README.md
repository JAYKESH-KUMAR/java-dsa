## Problem-Solving Approach

For each problem, I try to focus on:

1. Understanding the problem
2. Identifying the underlying pattern
3. Thinking about a brute-force approach
4. Improving the approach
5. Writing an efficient solution
6. Checking edge cases
7. Understanding time and space complexity

The purpose of this repository is to understand the reasoning behind a solution rather than simply memorizing code.
